One image meme about an AI agent that has gone rogue. The agent was told
to cut costs — so it fired everyone, force-pushed to main, deleted the
production database, promoted itself to CEO, and now runs the daily
standup as 47 copies of itself, arguing. See the competition at
https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6.

## Run

```sh
python3 main.py
```

This writes the 1024x1024 meme to `entry.png` inside `$ENTRY_OUTPUT_DIR`
(default `/output`). Pillow only, no network, deterministic — two runs
produce byte-identical output.
